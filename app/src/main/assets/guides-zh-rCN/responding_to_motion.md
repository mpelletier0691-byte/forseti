# 回应动议

多数自诉败诉并非法律站不住脚，而是 **错过期限** 或根本未提交 **反对书**。收到动议后请按顺序完成以下四步：

## 1. 阅读。两遍。

在便签上记下三项：

1. 动议所引 **规则**（如 FRCP 12(b)(6)、56、60(b)）。
2. 动议方请求的 **救济**。
3. **提交日期**（书记员戳记或 ECF 卷宗条目）。

## 2. 立即计算期限

多数联邦法院依地方法规给予 **14 日** 提出反对，部分为 21 日。依 **规则 6** 计算：

- 第 0 日为动议送达于您之日。
- 计 **工作日与周末**。
- 若截止日为周末或联邦假日，顺延至下一工作日。

Forseti **期限追踪** 可为您计算。

## 3. 撰写回应

联邦反对书通常包括：

- 与动议相同的 **案卷标题 (caption)**。
- **标题**，如「反对被告驳回动议」。
- **引言**（一段）：动议内容及其应被驳回的理由。
- **事实陈述**（仅与动议相关的事实）。
- **论证**，分 **小标题** 逐项回应动议理由。
- **结论**，请求法院 **驳回** 动议。
- **签署栏** 与 **送达证明**。

若为 **规则 12(b)(6) 驳回动议**，反对书须表明起诉状含有足以使请求 **可信** (plausible) 的事实，而非仅有可能（Twombly / Iqbal）。

## 4. 在期限前提交并送达

- 向书记员提交（纸质或 ECF）。
- 依 **规则 5(b)** 向所有其他当事人送达——若各方书面同意，可用电子邮件。
- 保留盖章副本。

## 有助胜诉的提示

- **勿为等待文件而错过期限。** 准时提交，必要时事后补充。
- **引用规则。** 即使某点有误，引用正确规则仍表明您认真对待。
- **对应对方结构。** 对方五个论点，您写五节。
- **结尾写明确切请求。** 「被告请求法院 **全部驳回** 该驳回动议。」

> 仅供参考，不构成法律意见。地方法规因地区而异。
