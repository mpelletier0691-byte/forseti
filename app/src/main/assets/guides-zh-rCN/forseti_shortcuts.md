# Forseti 快捷方式与安全工作流程备忘

本指南是应用内最快路径。仅描述 Forseti **当前实际具备** 的功能——不作承诺、不涉及路线图。若某步骤失效，请提交问题报告。

> **Forseti 理念。** 人工智能或许强大，但人的精神与毅力更为强大——愿此助您走完诉讼之路。我们不替您下结论；我们整理程序，让您有备而至。

---

## 1. 将 PDF *导入* 应用

四条同样快捷的路径，择时选用：

1. **文档扫描** 标签页——手上有纸质页时最佳。每页点 **捕获页面**，再 **保存 PDF 至案件**。若在标签字段输入 `motion`、`discovery`、`answer` 或 `order` 等关键词，Forseti 会自动归入对应阶段文件夹。
2. **分享到 Forseti**——在手机中打开任意 PDF（文件、Drive、邮件附件、扫描应用），使用系统 **分享** → 选择 **Forseti**。应用会询问归档为已上传规则还是案件工作区。
3. **已上传规则 → 导入 PDF**——用于 Forseti 无法自行获取的规则 PDF（州网站宕机、付费 HTML、您自己的批注版）。这些不会自动进入案件。
4. **案件档案 → 打开案件 → 导入文件**——在工作区任一子文件夹内。已知文件应放何处时最方便。

> **为何推荐分享到应用：** PDF 仅保存在 Forseti 私有空间，不会在相册或下载文件夹再留一份。

---

## 2. 自动归档（Forseti 如何决定存放位置）

将扫描或分享的 PDF 保存到案件时，Forseti 根据标签或文件名中的关键词路由至对应阶段文件夹：

| 标签/文件名中的关键词 | 目标位置 |
| --- | --- |
| `complaint` | `01_Pleadings/Drafts/` |
| `answer` | `02_Answer/Drafts/` |
| `motion`, `sanction` | `03_Motions/Drafts/` |
| `discovery`, `interrog`, `deposition`, `subpoena`, `rfp`, `rfa` | `04_Discovery/Drafts/` |
| `pretrial`, `trial` | `05_Trial/Drafts/` |
| `judgment`, `appeal` | `06_PostTrial/Drafts/` |
| `order` | `07_General/Drafts/` |
| `exhibit` | `<阶段>/Exhibits/`（若存在） |
| 其他 | `98_Scans/`（可稍后移动） |

可在 **案件档案 → 您的案件** 中通过重命名/分享/删除覆盖。

> **已上传规则 PDF 绝不会自动进入案件。** 它们留在「已上传规则」标签页，直至您主动分享出去。

## 3. 省时省事的拍摄习惯

- **页面铺平。** 扫描使用后置摄像头；卷曲页面会导致 PDF 变形。
- **每次填写标签。** 现在花三秒打字，日后才好找文件。
- **封面最后拍**，合并 PDF 时封面会在最前。
- **长文档每批不超过约 10 页。** 中途退出时，仅已保存部分会保留。
- **若希望文件直接进入案件工作区，优先用 Forseti 相机**，而非手机自带扫描——Forseti 仅自动归档其捕获或分享进来的内容。

## 4. 阅读规则时

**快速跳转** 是主要阅读界面。隐藏快捷方式：

- **书本图标** 打开快速跳转搜索——输入规则编号（如 "12(b)(6)"、"26"、"56(a)"）直达。
- **便签图标** 在页面上方打开速记。**保存** 后可在笔记标签页按页查看；**完成** 则丢弃。
- **书签图标** 将当前页标星，显示于笔记 → 书签列表。再次点按取消。
- **朗读图标** 对本页设备端 OCR 后，用 Android 在 *设置 → 无障碍 → 文字转语音* 中启用的语音朗读。**停止** 可中断。若无可用语音，应用可一键打开相关设置（或安装 Google TTS）。
- PDF 双指缩放；单指拖动滚动。
- 右下角页码显示当前位置。

### 长按复制/粘贴

在 **指南**、**笔记** 及案件 **文本/markdown 查看器** 中长按可拖动 Android 选择手柄，**复制** 至剪贴板以便粘贴到草稿、邮件或聊天。PDF 页面为图像，无法直接复制文字——此类情况请用 **朗读** 并手写速记。

---

## 5. 草稿与签名

**动议草稿** 标签页从内置模板生成可编辑 PDF——FRCP 风格动议与答辩外壳。Forseti 从不代您签名；打印草稿、手写签署后，用文档扫描重新捕获，使签署版与未签署草稿并存。

---

## 6. 备份

**备份** 标签页生成整个案件工作区的 ZIP。可存至 Drive、发邮件给自己或复制到 U 盘。在新安装 Forseti 上恢复可还原全部内容。

---

## 7. 了解局限

Forseti **仅提供信息，非法律意见**。应用：

- 捆绑公有领域 Federal Rules of Civil Procedure（2024 年 12 月 1 日版）
- 链接各州官方司法或立法网站上的州规则
- 缓存您选择下载的 PDF 以供离线使用
- 从不将案件数据发往外部；一切保留在本设备

若州链接 404，系州网站变更——请试 **参考文献** 标签页中较稳定的上级 URL，或通过 **已上传规则** 导入自有 PDF。

---

## 8. 坚韧者常用的工作流程

1. 打开 **案件档案** → 创建案件。
2. 打开 **期限** → 记录法院给出的每个日期。
3. 打开 **文档扫描** → 拍摄命令，标签 `order`。
4. 打开 **草稿** → 生成回应动议模板。
5. 打开 **快速跳转** → 重读命令所引规则。
6. 点 **便签图标** → 记下拟论证要点。
7. 在任意 PDF 应用中编辑草稿；打印、签署、再扫描入库。
8. 打开 **备份** → 出庭前 ZIP 整个案件文件夹。

此即循环。每项动议、每次听证、每次上诉皆如此。
