Brokkr Forge — background case import

This demo shows how Forseti uses a user-initiated foreground service during Brokkr Forge Process: the user selects a case folder to import; a persistent notification shows sorting progress; a completion notification appears when finished.

What the video shows

  1. User starts Brokkr Forge Process from Case Profile.
  2. Android notification: Brokkr Forge sorting… with file progress.
  3. User may leave the app while import continues on-device.
  4. Completion notification when sorting finishes.

Data sync only. Documents stay on the device; nothing is uploaded to a server.
